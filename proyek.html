02Testing

Pengujian Otomatis dengan Selenium

Sistem Informasi Pengolahan Nilai · Oktober 2026
  • Menyusun test case Black Box Testing untuk memverifikasi seluruh fungsi sistem multiperan sebelum dipakai pengguna, lalu mengotomatiskannya dengan Selenium WebDriver dan pytest.
  • Menyusun 30 test case di enam area: login dan sesi, hak akses antar peran, input nilai oleh guru, pencarian data oleh admin, fitur sisi siswa, dan pembukaan seluruh menu tiap peran.
  • Menguji skenario keamanan, yaitu percobaan SQL injection pada form login, akses halaman tanpa login, dan akses lintas peran, serta validasi nilai di sisi server dengan melewati batas input di browser.
  • Seluruh 30 test case lulus (100%), didokumentasikan lengkap beserta saran pengembangan.
  • Selenium
  • pytest
  • Python
  • Black Box Testing
